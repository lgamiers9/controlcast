## 📌 프로젝트 소개

KBO 리그의 **서울 LG 트윈스** 데이터분석팀이 제시한 문제를 다루는 해커톤 레포지토리입니다.

전통적으로 투수의 "제구력"은 ERA, BB%(볼넷 비율), K%(탈삼진 비율) 같은 결과 기반 지표로 평가되어 왔습니다. 하지만 이런 지표들은:

- **ERA** — 결과는 알려주지만 과정은 설명하지 못함
- **BB%** — 제구를 추정하지만 상황적 맥락이 빠짐
- **K%** — 구위 중심의 지표로, 제구와는 다른 차원의 개념

즉, **결과 지표만으로는 "제구가 좋다"를 설명하기 어렵습니다.** 이 프로젝트는 투구 단위(pitch-level)에서 "다음 투구의 제구 성공 확률"을 예측함으로써, 보다 세밀하고 상황 인지적인 제구력 평가 방법을 탐구합니다.

## 🎯 미션

> **다음 투구의 제구 성공 확률을 예측하라**

| 구분 | 기간 | 설명 |
|---|---|---|
| **Learn (학습 데이터)** | 2019 ~ 2024 시즌 | 투구별 입력 정보 + 학습용 Target 포함 (6시즌 누적) |
| **Predict (평가 데이터)** | 2025 시즌 | 투구별 입력 정보만 제공, Target은 비공개 → 제구 성공 확률 제출 |

2025 시즌 Target은 운영진이 비공개로 보유하며, 제출된 확률과 비교하여 모델 성능을 평가합니다.

## 🗂 제공 데이터 구조

투구 단위(pitch-level) 데이터셋이 아래 4가지 축으로 구성되어 제공됩니다.

| 축 | 설명 | 주요 정보 |
|---|---|---|
| 🎯 **경기 상황 정보** | 언제, 어떤 상황인가 | 볼/스트라이크/아웃, 이닝, 점수차, 주자 상황 |
| ⚖️ **경기 중요도 정보** | 얼마나 중요한 순간인가 | 기대승률(Win Expectancy), 상황 중요도(LI) |
| 📜 **과거 이력 정보** | 지금까지 어떻게 던졌나 | asof_* 누적 통계, 최근 경기 성과, 과거 구종 사용 패턴 |
| 📡 **Trackman 과거 로그** | 공의 물리적 특성 누적 | 구속, 회전수, 무브먼트, 릴리스 정보 (2019~2024) |

> ⚠️ 선수명은 제공되지 않으며, **익명 ID(투수 ID · 타자 ID · 팀 ID)** 기반으로 데이터가 제공됩니다.
> 세부 컬럼 정의는 별도 데이터 명세 자료를 참고하세요.

## 🔍 탐색해볼 수 있는 신호(Signal)

| 카테고리 | 신호 |
|---|---|
| 상황 | 경기 상황(카운트·이닝·주자), 경기 중요도(기대승률·LI) |
| 흐름 | 최근 흐름(3경기 트렌드·컨디션), 과거 이력(누적 통계·구종 사용) |
| 구질 | 구속(km/h), 회전수(rpm), 무브먼트(수평·수직), 릴리스 정보(위치·익스텐션) |

> 정답은 존재하지만, 문제를 해결하는 방법은 하나로 정해져 있지 않습니다.

## 💡 예측 결과의 현장 활용 가능성

투구별 예측을 상황별로 누적하면 다음과 같은 인사이트로 이어질 수 있습니다.

1. **상황별 제구력** — 주자 상황 / 카운트 / 이닝·경기 후반에 따른 제구 변화
2. **제구 안정성** — 최근 경기 흐름, 압박 상황 대응력, 변동성
3. **선수 평가와 육성** — 강점·약점 파악, 훈련 방향 설정, 성장 추적

예시 질문:
- "이 투수, 클러치에 강한가?" (주자 있을 때 제구력)
- "불리할 때도 승부할 수 있나?" (불리한 카운트 제구력)
- "오늘 7회까지 맡길 수 있을까?" (경기 후반 제구력)
- "오늘 등판시키는 게 맞을까?" (최근 제구 컨디션)

## ✅ 평가 기준 (Expectation)

| 항목 | 설명 |
|---|---|
| **정확한 예측** | Hidden Test 데이터에 대해 일반화 성능이 검증된 견고한 예측 모델 |
| **새로운 분석 아이디어** | 미처 보지 못한 변수, 새로운 피처, 다른 각도의 모델링 — 숫자 너머의 통찰 |

> "운영진이 미처 생각하지 못한 새로운 제구력 평가 방법" — 이런 발상의 전환이야말로 가장 기대하는 결과물입니다.
