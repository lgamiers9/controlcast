## 🎲 핵심 발견: BSS 지표의 노이즈 민감도

- 2022/2023/2024을 번갈아 홀드아웃으로 검증(leave-one-season-out)했더니 같은 모델이
  BSS 2000점대~0점대로 요동침 → 버그로 의심했으나, 실제로는 **BSS 공식 자체의 특성**
  (baseline Brier ≈0.25 근처에서 절대 오차 0.005~0.007의 작은 차이가 ±2000점까지 증폭됨)
- 부트스트랩(500회 재표본) 결과, 모든 조합의 BSS 표준편차가 **±45~52점**으로 나타남
  → 오늘 비교해온 "LGB+CAT(844.89) vs 4-way(825.88)" 같은 수십 점 차이는 **통계적으로
  유의하지 않음** (95% 신뢰구간이 서로 겹침)
- **결론**: 결합방식/조합 미세조정보다 신뢰도 높은 개선(피처 추가, 실제 버그 수정)에 집중하기로 함

## 🐛 발견 + 수정한 실제 버그: `GLOBAL_MEAN_SUCCESS` 하드코딩

- 에러분석(2024 홀드아웃 오차를 여러 축으로 그룹핑)에서, **투구 경험 적은 투수
  (`asof_pitcher_n` 0~5회)일수록 성공확률을 체계적으로 과대예측**하는 패턴 발견
  (예측 0.479 vs 실제 0.433, +4.6%p 편향)
- 원인: `feature_engineering.py`의 베이지안 스무딩(`asof_pitcher_success_smoothed`)이
  `GLOBAL_MEAN_SUCCESS = 0.55`라는 하드코딩된 상수로 신인급 투수 예측을 잡아당기고 있었는데,
  실제 시즌별 성공률은 계속 하락 추세(2023=0.500, 2024=0.486)라 0.55는 낡은 값이었음
- 수정: `build_lookups()`에서 학습데이터 실제 평균(2019~2024 기준 **0.524**)을 동적으로
  계산해서 넘겨주도록 변경 (`feature_engineering.py`)
- 검증: 기존 하이퍼파라미터로 재테스트 시 4-way 스택 +3.15, 새로 HPO 재탐색 후 +3.07 —
  **두 번 독립적으로 일관된 방향(+)** 으로 나와서 노이즈가 아닌 진짜 개선으로 판단
